Notebook

Type in real math notation — fractions, exponents and roots render as you go. Declare anything: P = x^2 + 1, then P*Q/(P+Q). Reference any matrix by its name: A^2 + B + Identity. A name assigned to a plain number, like a = 1, stays a symbol in later lines rather than being substituted — write the number directly if you want a literal value. Lowercase x is the free polynomial variable and i is the imaginary unit; neither can be reassigned. Everything recomputes live as you type.

Computed in your browser with the original Python engine, run via Pyodide. Nothing is sent to a server.
